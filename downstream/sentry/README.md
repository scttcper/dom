# Sentry downstream suite

[Sentry](https://github.com/getsentry/sentry)'s frontend tests (Jest, with Sentry's own setup files), unmodified, on jsdom and on @ctrl/dom.

## Run

```sh
pnpm build                                   # ctrl-dom-full runs our built packages (packages/*/dist)
pnpm downstream:sentry --install                                                             # first run: clone the pinned commit and install its dependencies
pnpm downstream:sentry --preset all --modes jsdom,ctrl-dom,ctrl-dom-full --workers 4  # what the results below track
```

Presets: `smoke` (15 files), `perf` (39 files, for quick A/B runs), `components` (`static/app/components`, 653 files), `views` (~250 files) and `all` (every spec, ~2,400 files: what the results track).
