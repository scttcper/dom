# @ctrl/dom/aria

ARIA roles, accessible name/description and states on `@ctrl/dom`. It replaces `aria-query` and
`dom-accessibility-api` inside `@ctrl/dom`. Used by `@ctrl/dom/testing-library` and
`@ctrl/dom/jest-dom`; you rarely need it directly.
